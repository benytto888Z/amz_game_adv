AMZ PIXEL — TESLA PREMIUM / PROTOTYPE HTML

Ouvrir index.html dans un navigateur récent.
Fichiers : index.html, css/style.css, js/app.js.

Cette version est une maquette front-end responsive avec 7 écrans, thème clair/sombre,
éditeur de message et prévisualisation simulée d'une matrice 32 x 8.

IMPORTANT : aucune communication réelle avec l'ESP32 n'est intégrée. Les fonctions
connexion, envoi, luminosité et alimentation sont des simulations d'interface.
L'intégration HTTP/JSON avec le firmware reste à développer et tester.
Les polices Google nécessitent Internet ; des polices de secours sont prévues.
